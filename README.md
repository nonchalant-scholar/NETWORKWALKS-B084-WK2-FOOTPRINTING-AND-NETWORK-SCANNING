## Scope and Methodology

- Domain footprinting involved collecting publicly available domain, DNS and web-response information.
- Network host discovery was performed on the practitioner's own personal mobile-hotspot network.
- Activities focused on information gathering and host discovery.
- No exploitation, credential attacks or intrusive vulnerability testing were performed.
